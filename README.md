# SwitchLang

Нативная фоновая утилита для исправления текста, набранного в неправильной раскладке.

Сайт проекта: [iglakovmaks.github.io/SwitchLang](https://iglakovmaks.github.io/SwitchLang)

На сайте доступны готовые сборки для macOS и Windows, промо-видео и скриншоты приложения.

```text
руддщ → hello
ghbdtn → привет
```

## Поведение

SwitchLang не назначает собственную горячую клавишу и не угадывает направление. Он отслеживает системную смену раскладки:

1. Пользователь выделяет ошибочный текст.
2. Нажимает своё обычное сочетание переключения языка.
3. SwitchLang видит переход RU → EN или EN → RU.
4. Текст преобразуется из предыдущей раскладки в новую.
5. Исправленный фрагмент остаётся выделенным, поэтому повторное переключение возвращает его обратно.

Поддерживаются стандартные русская и английская раскладки. Другие раскладки игнорируются.
Знак вопроса `?` сохраняется без изменений в обоих направлениях.

Общий исходный значок приложения — [icon.png](icon.png). На macOS он упаковывается в `.icns`, а на Windows — в `.ico` и используется также для tray-иконки. В строке меню macOS остаётся компактная надпись `SL`.

## Нативные клиенты

### macOS

Swift/AppKit-клиент находится в [macos](macos). Он работает как приложение в menu bar, получает выделение через Accessibility API и использует копирование/вставку только как fallback для редакторов, которые не поддерживают прямую замену текста.
Двойной клик по значку приложения снова открывает окно настроек.

Сборка:

```bash
cd macos
swift build -c release
./build-app.sh
open dist/SwitchLang.app
```

Установочный образ `.dmg` собирается командой `./create-dmg.sh`. Внутри образа находятся SwitchLang и ярлык для папки Applications.

Для работы macOS попросит разрешить приложению управление компьютером в `Системные настройки → Конфиденциальность и безопасность → Универсальный доступ`. Если используется fallback через Apple Events, может понадобиться также разрешение в разделе «Автоматизация».

Если в окне SwitchLang отображается красный статус «Доступ не выдан», добавьте именно собранный файл `macos/dist/SwitchLang.app` в список «Универсальный доступ». После пересборки macOS иногда считает приложение новой версией: в таком случае удалите старую запись SwitchLang и добавьте текущую заново, затем перезапустите приложение.

### Windows

C#/.NET WinForms-клиент находится в [windows](windows). Он работает из системного трея, определяет раскладку через Win32 `GetKeyboardLayout`, а выделение заменяет через native clipboard и `SendInput`.
Двойной клик по значку в системном трее открывает окно приложения.

Сборка на Windows:

```powershell
cd windows
dotnet build -c Release
dotnet run -c Release
```

Сборка проекта также проверяется с macOS с включённым `EnableWindowsTargeting`.

## Автозапуск

В нативных клиентах есть пункт «Добавить в автозапуск»:

- macOS регистрирует приложение через `SMAppService`;
- Windows добавляет запись текущего пользователя в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.

## Ограничения

- защищённые поля, удалённые рабочие столы и нестандартные редакторы могут запретить чтение или замену выделения;
- fallback использует системный буфер обмена, но старается восстановить его после операции;
- сложные текстовые редакторы могут не поддерживать прямой Accessibility/UI Automation доступ.

## Проверки

```bash
python3 -m unittest discover -s tests -v
cd macos && swift build -c debug
cd windows && dotnet build -c Debug
```

Python-файлы в корне сохранены как ранний прототип и тестовый reference для алгоритма преобразования; для использования приложения следует собирать нативный клиент соответствующей ОС.
